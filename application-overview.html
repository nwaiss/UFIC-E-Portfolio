Application Overview

The Princess Vlei Forum is a Cape Town non-profit protecting the Princess Vlei wetland. Their site contains over 200 historical articles and general information pages. Our team built the Princess Vlei Assistant, an AI chatbot embedded on every page, so visitors can ask direct questions about the vlei's history, wildlife, conservation work, and visiting details rather than searching through the archive.

The chatbot is a single self-contained JavaScript file with no framework or build step, automatically injected across all 230-plus pages on the site. It runs on Cloudflare Workers, an edge platform that serves content from data centers close to each visitor. When someone asks a question, the browser sends that message along with up to six prior exchanges to a separate AI backend, which queries a language model and returns a formatted response rendered client-side. Every link the AI suggests is validated against a trusted domain allowlist before it becomes clickable; anything outside the list appears as plain text only.

The backend was built with cost control and reliability in mind. It runs a primary-to-backup AI provider fallback, so if the main model is slow, over budget, or unavailable, the system switches automatically and shows users a clear notice rather than failing silently. Each request sends only the last six messages of conversation history to keep usage predictable, and visitors are assigned an anonymous per-browser ID for server-side rate-limiting with no personal data collected or stored. Conversational testing and guardrail validation were conducted manually against the live backend, with the link-safety guardrail directly observable in the working product.
